### 👋 Hi there — I'm Ahmed Elbossily

I'm a **Research Assistant and Ph.D. Candidate at Leuphana University**, working on **GPU computing, high-performance computing, scientific software, and numerical simulation**.

My research focuses on developing **C++/CUDA GPU-accelerated solvers** for large-scale **particle-based** simulations and computational mechanics applications.

---

### 💻 Current Focus

* ⚡ GPU programming with **CUDA/C++**
* 🚀 High-performance and parallel computing
* 🧮 Numerical methods and scientific computing
* 🔬 Large-scale particle simulations
* 🔬 Smoothed Particle Hydrodynamics (SPH)
* 📊 Performance optimization and profiling
* 🧩 Scientific software development
